# DailyBit

개인 개발 학습 기록 블로그. 공부한 내용을 짧은 글(Bit)로 남기고, 연결된 탐구 과정을 Thread로 엮는다.

## 목적

- 혼자 공부하며 배운 것을 날마다 기록한다
- 단발 메모뿐 아니라, 하나의 주제를 파고드는 과정을 Thread(타래)로 이어 쓴다
- GitHub 스타일 Garden으로 꾸준함을 시각화한다
- 스킬 태그 필터로 포트폴리오처럼 기술 영역별로 탐색한다

## Stack

- Next.js 16 App Router + TypeScript
- Tailwind CSS + shadcn/ui
- Prisma + Supabase (PostgreSQL)
- Vitest + React Testing Library
- Vercel 자동 배포

## 실행

```bash
pnpm dev
```

## 주요 개념

| 용어 | 설명 |
|------|------|
| Bit | 핵심 단위. 500자 이내 짧은 학습 기록 |
| Thread | 탐구 타래. 하나의 주제를 단계별로 이어 쓴 Bit 묶음 |
| Garden | 1년간 활동을 잔디밭으로 시각화. Thread Bit 2pt, 독립 메모 1pt |
| Tag | #태그로 스킬 영역 분류. 태그 필터로 포트폴리오처럼 탐색 가능 |
| Pin | 중요한 Bit를 상단 고정 |
